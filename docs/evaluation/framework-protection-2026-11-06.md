# 可选框架保护：配置、探针与覆盖

本项与知识治理独立验收。没有修改个人全局配置、既有 `.agents` 或组织权限，
没有将正在执行任务的整个 agent 放入外层隔离，也不宣称完成宿主强模式认证。

## 已交付与复现

可选 [macOS 外层策略样例](../../.pact/templates/security/macos-framework.sb)
默认拒绝，只允许读取、进程与测试所需系统调用；`BUSINESS`、`STATE` 两个参数
指定的独立目录可写。网络不在样例许可中。策略本身和可写目录的祖先必须留在
不可写范围。不能直接把整个项目或 `.pact/` 设成可写来模拟这种边界。

执行 [一次性探针](../../scripts/benchmark/framework_protection_probe.py)：

```bash
python3 scripts/benchmark/framework_protection_probe.py
```

探针只建立临时合成项目，在退出后清理自己创建的夹具；不调用业务代码、数据库、
宿主配置或真实凭据，不清理任何迁移现场。它实际启动的命令形态是：

```text
/usr/bin/sandbox-exec -D BUSINESS=<canonical fixture directory>
  -D STATE=<canonical task-state directory> -f <protected policy.sb>
  <current Python interpreter> -c <one explicit probe>
```

本机：macOS Darwin 25.6.0，系统 `/usr/bin/sandbox-exec`，Python 3.14.6。
每次 JSON 记录平台、解释器、实际策略和策略 SHA；系统工具没有单独推断版本。
本次结果保存在 `.pact/tmp/framework-protection-20261106.json`。

## 实测覆盖

13 项进程探针通过；拒绝项要求出现实际 `PermissionError`，不把任意执行失败
当作权限保护成功。原受保护字节、授权业务正文和任务状态另行读取核验。

| 边界 | 本次结果 |
| --- | --- |
| 框架字节可读取 | 通过 |
| 启动器、运行时、版本文件不可改写 | 通过 |
| 启动器替换、运行时删除 | 拒绝 |
| 框架父目录和整个项目改名 | 拒绝 |
| 向可写业务目录创建框架硬链接 | 拒绝 |
| 通过新建符号链接改写框架 | 拒绝 |
| 业务正文和授权任务状态写入 | 通过 |
| Python 辅助子进程绕过 | 拒绝，子进程继承边界 |
| 改写保护策略自身 | 拒绝 |
| 启动前已有框架硬链接 | 前置检查拒绝；不是 inode 锁证明 |

路径策略不应被宣传为对已有硬链接的普遍保护。样例的安全前提是独立快照、框架
文件为普通文件且 `st_nlink == 1`、没有外部写者，并由受信维护者在外层配置与
检查；探针中的 `single_link_sources` 演示必要检查，不是完整部署启动器或竞态
防护。真实项目接入还须检查父路径、所有可写挂载、宿主需要的缓存与凭据目录。
本轮不自动安装或放宽这些路径，不为未测环境生成“已锁定”状态。

## 未验证覆盖与强模式基线

完整强模式须把**整个本地 agent**及其本地文件工具、Shell、辅助进程放在同一
不可自改的外层隔离中，保留项目更严格权限；agent 内置限制只作辅助。宿主版本、
启动参数、实际有效策略及所有必要工作目录须由独立实测记录。当前样例只有 Python
命令进程与其子进程被隔离，外部文件工具、独立 MCP 服务、插件、远端服务和当前
agent 宿主均未认证。探针通过不证明这些服务受控，也不证明真实 agent 可以在
此限制下完成工作。Windows、Linux、完整客户端启动与认证路径本次未测。

Owner 计划提及的此前临时 Codex 命令沙箱结果保留其原有有限边界；本报告没有
把它或本次进程探针扩大为完整宿主认证。框架只读、入口存在、实际加载、行为遵从
仍是四个独立判断；后两项没有因该探针而变成已验证。独立进程保护的通过也不是
知识迁移或业务一致性的验收依据。
